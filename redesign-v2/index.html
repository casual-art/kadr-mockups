Stany checklisty

  • ✓ złapane — kadr w galerii
  • ↺ retake — obie wersje zostają
  • ● teraz — krok w świetle (glow)
  • ○ następny — czeka w ciszy
  • pasek postępu: zielony = złapane · złoty = teraz · szary = przed

Mapowanie T4/T8

Push „Zostały ci 2 ujęcia w «Urodziny mamy»" → deep-link otwiera checklistę z karty kontynuacji (oba pulpity). Push „Montaż gotowy" → Pokój Montażowy. Push bez deep-linka to zmarnowany push (RETENCJA §4).

Co zostaje z krytyki

S2 powitanie + kroki „bo…" 1:1 · S1 string „● Zaczynam nagrywać" 1:1 · S3 MOD-y i PRO-card 1:1. Wypadło: emoji jako treść scen (→ sylwetki), gradient CTA (→ glow), „Odpuszczono." Przerobione: „Nakręć tak samo" → „Zaczynam nagrywać", „zielona-kropka KAŻDY" → „dla każdego", „PUŁAPKA ✕" → „Uważaj:".
